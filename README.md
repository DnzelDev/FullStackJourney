# 🚀 FullStackJourney

Ruta de aprendizaje personal hacia convertirme en desarrollador Full Stack, construida desde Ingeniería de Sistemas — documentando cada paso, desde los fundamentos hasta proyectos aplicados.

## 🧭 Filosofía

- **Primero entender la lógica, después escribir código.** Nunca copio soluciones completas generadas por IA.
- La IA se usa como mentor y revisor, nunca como generador de soluciones — pistas progresivas en vez de respuestas directas.
- Dominio real antes de avanzar: el ritmo de cada tema depende de qué tan sólido lo tenga, no de un cronograma fijo.
- Cada concepto nuevo se practica dentro de un **escenario aplicado** (un mini-sistema con contexto real, como un banco o un inventario), no solo con ejercicios sueltos y abstractos — mejor retención por repetición de patrones en contextos distintos.

## 📁 Estructura

```
FullStackJourney/
├── 01_Aprendizaje/      → práctica de conceptos aislados, por lenguaje/tecnología
├── 02_Proyectos/        → aplicaciones reales que demuestran lo aprendido
├── 03_Apuntes/          → notas propias de cada concepto, en mis propias palabras
├── 04_Recursos/         → material externo de consulta (cursos, guías, referencias)
└── 05_Git/              → control de versiones (en configuración)
```

- **`01_Aprendizaje`** es la biblioteca personal: cada tema (incluso los ya dominados) tiene ejemplos claros para consultar en el futuro, sin depender de buscar en internet.
- **`02_Proyectos`** es donde la teoría se convierte en software funcional — con reglas propias: variedad entre proyectos tipo *juego* y tipo *sistema real*, y un filtro de calidad antes de subir algo aquí (no todo lo que se practica termina siendo mostrado).

## Nota importante sobre este roadmap

Los temas 06_POO a 12_MVC están alineados al sílabo de Programación
Avanzada (ciclo 4, 2026-02) para llegar preparado a clases. Esto NO
significa que Java "termine" ahí — es solo el próximo tramo visible.

Después de completar estos temas, el roadmap se sigue extendiendo con
lo que vaya apareciendo: nuevos cursos de la universidad, y temas de
autoaprendizaje (testing, Streams/Lambdas, Generics avanzados, Maven/
Gradle, Spring Boot completo, etc.) según lo que vaya necesitando el
journey. No hay una "meta final" fija — Java se sigue extendiendo
mientras siga en la carrera.
